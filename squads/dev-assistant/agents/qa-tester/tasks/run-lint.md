# Task: Rodar Lint

## Descrição
Executar linter e corrigir problemas automáticos.

## Processo

```bash
# Root
npm run lint

# Fix auto
npm run lint -- --fix
```

## Output
Relatório:
- Errors restantes
- Warnings
- Arquivos com problemas

Se errors > 0 após fix automático → reportar ao Senior Dev
