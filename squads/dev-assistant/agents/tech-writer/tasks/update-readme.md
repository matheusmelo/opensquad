# Task: Atualizar README

## Descrição
Manter o README principal atualizado com mudanças no projeto.

## Quando Executar
- Nova feature adicionada
- Comando novo disponível
- Mudança breaking na API
- Nova squad criada

## Processo

1. **Verificar seções do README:**
   - [ ] Título e descrição
   - [ ] Como usar (comandos)
   - [ ] Squads disponíveis
   - [ ] Skills instaladas
   - [ ] Deploy instructions
   - [ ] Contributing guide

2. **Adicionar novidades:**
   - Nova squad `dev-assistant` → documentar
   - WhatsApp integration → documentar comandos
   - Orchestrator → documentar endpoints

3. **Exemplo de atualização:**

```markdown
## Squads Disponíveis

### Shlomo Engineering 🔧
Processa faturas, classifica transações, constrói dashboards.

**Comando:**
```
/shlomo processe minha fatura do Nubank
```

### Dev Assistant 👨‍💻
Assistente autônomo para tarefas de desenvolvimento.

**Comando:**
```
/dev implemente upload de PDFs
/dev debugue erro no parser
```
```

## Output
README.md atualizado com:
- Novas squads documentadas
- Comandos atualizados
- Screenshots (se UI mudou)
