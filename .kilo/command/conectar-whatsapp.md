# /conectar-whatsapp

Conecta seu WhatsApp ao orchestrator para controlar agentes e squads via mensagens.

## Uso

```
/conectar-whatsapp
```

## O Que Faz

1. **Inicia WhatsApp Bot** em modo interativo
2. **Gera QR Code** no terminal para escanear
3. **Configura webhooks** automaticamente
4. **Testa conexão** com orchestrator
5. **Mostra comandos disponíveis**

## Após Conectar

Você poderá enviar pelo WhatsApp:

### Comandos de Desenvolvimento
```
/dev implemente gráfico de pizza
/debug corrija erro no parser
/deploy faça deploy em produção
```

### Consultas Financeiras
```
Quanto gastei com Uber esse mês?
Mostra saldo atual
Qual pulmão está mais cheio?
```

### Controle de Squads
```
/status shlomo-engineering
/executar squad gestao-pessoal
/parar todos os agentes
```

### Monitoramento
```
/custos hoje
/quem está trabalhando?
/relatório semanal
```

## Output Exemplo

