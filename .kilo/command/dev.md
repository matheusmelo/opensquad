# /dev

Execute tarefas de desenvolvimento autônomas com a squad Dev Assistant.

## Uso

```
/dev <descrição da tarefa>
```

## Exemplos

### Features
```
/dev implemente componente de upload de PDFs
/dev adicione filtro por data no dashboard
/dev crie endpoint POST /api/rules/suggest
```

### Bug Fixes
```
/dev corrija tipo no LungCard.tsx
/dev resolva erro no parser do Nubank
/dev fixe memory leak na sessão WhatsApp
```

### Refatoração
```
/dev extraia validação para função separada
/dev otimize queries do Prisma
/dev remova todos os any do código
```

### Deploy/Infra
```
/dev configure deploy automático no Railway
/dev adicione healthcheck endpoint
/dev setup backup do database
```

### Documentação
```
/dev documente API endpoints
/dev crie ADR para escolha de database
/dev atualize README com novos comandos
```

## O que acontece

1. **Senior Dev** analisa e implementa
2. **QA Tester** valida (lint, tests, build)
3. **Tech Writer** atualiza docs
4. Resultado entregue com relatório
